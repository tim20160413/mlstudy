# 概念库

数学/统计基础概念笔记：分布、估计方法、优化理论等。每个概念单独一篇，用 `[[概念名]]` 从模型笔记（`models/`）里引用，避免同一个概念在多篇模型笔记里重复展开、逐渐不一致。

用 [templates/concept-template.md](../templates/concept-template.md) 新建条目。

不要求覆盖教材式的全部内容，只写对理解模型有直接帮助的部分（定义 + 为什么是这个形式），详细推导/证明不是重点。
