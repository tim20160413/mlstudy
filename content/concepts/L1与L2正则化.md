# L1与L2正则化

## 一句话总结
在损失函数上加一个惩罚项限制参数的大小，L2（岭回归）让所有权重平滑收缩但不归零，L1（Lasso）会把不重要的权重直接压成零，两者的差异来自惩罚项的几何形状，而不是任意的工程选择。

## 定义
在原始损失 $L(w)$ 上加惩罚项：
- L2 正则化（岭回归）：$L_{\text{ridge}}(w) = L(w) + \lambda \|w\|_2^2 = L(w) + \lambda \sum_j w_j^2$
- L1 正则化（Lasso）：$L_{\text{lasso}}(w) = L(w) + \lambda \|w\|_1 = L(w) + \lambda \sum_j |w_j|$

$\lambda \geq 0$ 控制正则化强度，$\lambda = 0$ 退化为无正则的原始问题。

线性回归下 L2 正则化有闭式解：$w^* = (X^TX + \lambda I)^{-1}X^Ty$——加入 $\lambda I$ 后矩阵保证可逆，这也是它能解决共线性/维度过高导致 $X^TX$ 不可逆问题的直接原因。L1 正则化没有闭式解，需要用坐标下降、次梯度法等迭代方法求解。

## 直观理解
- **为什么要加正则项**：无正则时，训练损失最小化会让模型尽力拟合训练数据中的每一个细节（包括噪声），参数可能变得很大、对输入的微小扰动很敏感（方差高）。正则项相当于告诉优化过程"除了拟合数据，也要让参数保持简单/小"，用可控的偏差换取方差的下降，这是偏差-方差权衡的具体手段。
- **几何视角（为什么 L1 产生稀疏性，L2 不会）**：
  - 带约束形式等价地写成 $\min L(w)$ s.t. $\|w\|_p \leq C$：L2 约束对应一个圆形（球形）区域，L1 约束对应一个菱形（多面体）区域
  - 损失函数的等高线与约束区域边界的交点就是最优解。圆形边界处处光滑，交点几乎不会恰好落在坐标轴上；菱形有尖角，且尖角正好在坐标轴上，等高线更容易先碰到这些尖角——这意味着某些坐标（权重）被直接压成 0
  - 这就是为什么 L1 能做特征选择（稀疏解），L2 只能让权重整体变小但保留所有特征
- **概率视角（贝叶斯先验）**：
  - 正则化等价于对参数 $w$ 加一个先验分布，再做最大后验估计（MAP）而不是单纯 MLE
  - L2 正则化 ⟺ 假设 $w_j \sim N(0, \tau^2)$（高斯先验），先验在 0 附近集中但尾部迅速衰减，推出的惩罚是平滑的二次项——呼应 [[高斯分布与最大似然估计]] 里"噪声分布假设决定损失函数形式"的逻辑，这里是"参数的先验分布假设决定正则项形式"
  - L1 正则化 ⟺ 假设 $w_j \sim \text{Laplace}(0, b)$（拉普拉斯先验），这个分布在 0 处有尖峰，所以 MAP 解更容易直接落在 0 上，这与几何视角的"尖角"结论一致

## 关联模型
- [[线性回归]]：无正则闭式解在 $X^TX$ 不可逆时失效，加 L2 正则（岭回归）后恒可逆；这是阶段一"适用边界"里提到的共线性问题的直接应对手段
- 逻辑回归、神经网络等几乎所有带参数优化的模型都可以加 L1/L2 正则，不是线性回归专属

## 关联概念
- [[最小二乘法]]：无正则的线性回归闭式解，是本概念"$\lambda=0$ 退化情形"的参照
- [[高斯分布与最大似然估计]]：正则化的贝叶斯先验视角与噪声分布视角是同一套"分布假设决定目标函数形式"逻辑的两个应用
