## 核心实现要点
- 前向计算：`y_pred = X @ w + b`，用 numpy 矩阵乘法向量化，避免逐样本 for 循环
- 损失函数实现：MSE，`loss = np.mean((y - y_pred) ** 2)`
- 梯度/更新规则（批量梯度下降版本）：
  - `grad_w = -(2/n) * X.T @ (y - y_pred)`
  - `grad_b = -(2/n) * np.sum(y - y_pred)`
  - 更新：`w -= lr * grad_w`，`b -= lr * grad_b`
- 数值稳定性处理：
  - 特征做标准化（零均值单位方差），否则不同量级的特征会导致梯度下降在不同方向上收敛速度差异巨大，学习率难选
  - 闭式解中 $X^TX$ 接近单奇异时，用 `np.linalg.pinv` 代替 `np.linalg.inv`，或直接用 `np.linalg.lstsq`
- 向量化要点：所有样本的前向、损失、梯度计算全部用矩阵运算完成，不写 Python 级别的样本循环

## 复杂度分析
- 时间复杂度：
  - 闭式解：$O(nd^2 + d^3)$
  - 梯度下降：每轮 $O(nd)$，共 $T$ 轮则 $O(Tnd)$
- 空间复杂度：$O(nd)$（存储特征矩阵）
