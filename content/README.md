# 机器学习学习平台

自己整理机器学习模型学习方法论的内容仓库，长期目标是打磨成一个对任意学习者公开的网站。现阶段先用 Markdown 把内容结构和方法论本身跑通，验证之后再决定要不要迁移到正式的 Web 平台（如 Next.js + 数据库）。

## 目录结构

```
mlstudy/
├── methodology/          # 方法论本身（三阶段学习法的详细说明）
├── templates/            # 模型 / 论文 / 案例的内容模板
├── models/               # 按类别组织的模型条目，每个模型走三阶段
│   ├── classical-ml/     # 经典机器学习（当前优先级）
│   ├── deep-learning/    # 深度学习基础架构（后续扩展）
│   ├── llm/              # 大模型相关（后续扩展）
│   └── recsys/           # 推荐/搜索等业务模型（后续扩展）
├── papers/               # 论文阅读库，关联到具体模型
├── cases/                # 大厂模型落地案例库，关联到具体模型
└── concepts/             # 数学/统计基础概念库，关联到具体模型
```

## 核心方法论：模型学习三阶段

每个模型条目都按以下三个阶段组织，详见 [methodology/three-stage-framework.md](methodology/three-stage-framework.md)：

1. **研究员视角** — 按模型三要素（模型 / 策略 / 算法）理解模型本身
2. **算法工程师视角** — 从零实现模型，并做优化调参
3. **数据科学家视角** — 结合业务场景、指标体系做方案对比和落地思考

Papers 和大厂落地案例作为两个独立的内容库，通过关联字段挂到具体模型条目上，不是每篇论文/案例都要求走完三阶段。
